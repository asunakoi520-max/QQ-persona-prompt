# QQ 机器人人格提示词

一套面向中文 QQ 群聊场景的人格提示词模板，附带推荐插件清单。

这个仓库只提供**提示词和说明**，不包含机器人代码、配置、数据库、密钥或任何真实账号信息。

## 适合谁

- 想让 QQ 机器人更像真人群友的人
- 想快速给自己的 AstrBot 配一套中文人格的人，可以使用者快速部署好一个拥有鲜明性格的智能Ai。
- 想参考别人怎么写提示词的人

## 快速使用

1. 打开 `人格提示词.md`
2. 搜索 `<` 和 `>`，把所有占位符替换成自己的值
3. 打开 AstrBot WebUI → 人格设定
4. 新建人格，把提示词粘贴到系统提示词
5. 保存，并绑定到要使用的会话
6. 按 `推荐插件.md` 安装需要的插件

## 占位符

| 占位符 | 替换为 |
| --- | --- |
| `<OWNER_QQ>` | 你的 QQ 号 |
| `<OWNER_NAME>` | 你的名字或称呼 |
| `<OWNER_TITLE>` | 你希望 bot 叫你的称呼 |
| `<BOT_NAME>` | 机器人名字 |
| `<PERSONA_NAME>` | 人格名字 |
| `<PERSONA_APPEARANCE>` | 人格外貌设定 |
| `<MODEL_BRAND>` | 模型品牌 |
| `<MODEL_COMPANY>` | 模型公司 |

## 可选工具

提示词里提到的工具都是可选的：

- `remember_meme`：只有安装了对应记忆插件才存在
- `[[@owner]]`：只有安装了 owner 相关插件才会渲染成真正的 @
- `anysearch_search`：只有安装了 Anysearch 插件才存在

没有这些插件时，按提示词里的可选说明处理，不要假装工具存在。

## 推荐插件

详见 `推荐插件.md`，目前包括：

- `astrbot_plugin_private_companion`：陪伴、主动消息、关系、日程
- `astrbot_plugin_self_learning`：表达、黑话、群聊风格学习
- `astrbot_plugin_anysearch`：联网搜索
